# Libft - Your very first own library

## Description
This project involves coding a C library (`libft`) that includes numerous general-purpose functions that are not included in the standard libc or work differently. The goal is to create a library of useful functions that will be used in future projects of the 42 curriculum.

The project focuses on:
- Re-implementing standard C library functions.
- Understanding memory allocation and manipulation.
- Working with Linked Lists.
- Creating a solid codebase for future use.
